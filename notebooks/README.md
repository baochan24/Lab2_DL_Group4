# Notebook — dùng cho khám phá và trình bày

Notebook không nên chứa lại toàn bộ logic train; phần tái sử dụng đặt trong `src/`.

- `01_dataset_exploration.ipynb` — TV1: mẫu ảnh CIFAR-10, tên lớp, shape, preprocessing.
- `02_results_analysis.ipynb` — TV4: đọc metrics đã đo, biểu đồ so sánh, TensorBoard observations.

Chỉ ghi kết quả thật sau khi notebook được chạy. Không commit output khổng lồ hoặc dữ liệu tải về trong notebook.
