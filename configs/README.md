# Cấu hình thí nghiệm — TV5

Mỗi cấu hình cần ghi tối thiểu:
- `experiment_name`
- `model_name`
- `pretrained`
- `batch_size`
- `learning_rate`
- `epochs`
- `strategy` (classifier-only hoặc fine-tuning)
- `seed`
- `data_dir`
- `log_dir`
- `checkpoint_dir`

Các file YAML dưới đây chỉ là mẫu TODO, chưa phải cấu hình đã được xác nhận. Chốt giá trị sau khi kiểm tra VRAM và thời gian chạy.
