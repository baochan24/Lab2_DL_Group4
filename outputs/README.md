# Outputs

## Sẽ lưu sau khi chạy thực nghiệm
- `experiment_summary.csv`: config và metrics thực đo.
- `figures/`: biểu đồ đã chọn để đưa vào báo cáo.
- TensorBoard logs: lưu cục bộ trong thư mục runs (đã ignore).
- Checkpoint: lưu cục bộ hoặc artifact storage theo thống nhất nhóm.

Không điền số liệu ước lượng. Không commit file nặng khi chưa được nhóm đồng ý.
